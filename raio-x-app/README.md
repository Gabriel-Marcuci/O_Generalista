# Raio-X da Clínica — App Vercel

Quiz interativo para diagnóstico comercial de clínicas de estética.

```sh
npm install
npm run dev        # http://localhost:3000
npm run build
npm start
```

Deploy via Vercel: `vercel deploy`

O motor roda na API em `/pages/api/avaliar.js`. Sem DB, sem cookie tracking.
