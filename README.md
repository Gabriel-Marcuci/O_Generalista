# Sistema de Vendas Invisível

> O teu Instagram virando máquina de venda — dentro do Claude Code.

Você acabou de instalar o Sistema de Vendas Invisível. Em alguns minutos, teu negócio vai ter uma memória própria — quem você é, como você fala, o que você vende — e um time de habilidades que escreve teu discurso, teus posts de venda e teu fluxo de fechamento, tudo calibrado pra ti.

A regra é uma só: **POST → SCRIPT AUTOMÁTICO → PIX NA CONTA.** O post atrai quem já quer comprar, o script conduz no Direct, o Pix cai. Sem viralizar, sem postar todo dia, sem lançamento.

Bora vender.

---

## Ligando o sistema

Dois caminhos. Escolhe o que combina contigo.

### Pelo Claude (mais rápido)

Abre o Claude Code em qualquer pasta e cola:

```
Clona o https://github.com/Gabriel-Marcuci/O_Generalista.git na pasta atual,
entra nela e roda o /instalar.
```

Ele clona, entra na pasta nova e dispara a entrevista de setup. Você só responde.

### Pelo terminal (mais previsível)

```
git clone https://github.com/Gabriel-Marcuci/O_Generalista.git
cd O_Generalista
code .
```

Na janela do VS Code que abrir: terminal integrado → `claude` → `/instalar`.

---

Quando o `/instalar` terminar, renomeia a pasta `O_Generalista/` pro nome do teu negócio (fecha o VS Code, renomeia no Finder, abre de novo). A pasta não fica como "O_Generalista" — ela é o teu negócio agora.

O `/instalar` roda uma vez só. Te entrevista, monta a memória e calibra o sistema pro teu nicho. Depois disso, é só usar.

---

## O sistema

**Núcleo** — o que te guia
`/comecar` lê onde você está e te leva pro próximo passo, do zero ao primeiro PIX · `/instalar` configura o sistema pro teu negócio (roda uma vez).

**O método** — do discurso ao fechamento
`/discurso` constrói teu discurso, teu método (em 3 etapas) e tua proposta · `/perfil` transforma teu Instagram em vitrine que converte · `/pvd` escreve teus Posts de Venda Direta (9 cards) que atraem comprador, não curioso · `/fvd` monta o fluxo de venda no Manychat (7 blocos, dois caminhos).

**Escala** — só depois das primeiras vendas
`/monetizacao` monta tua escada de produtos (order bump, upsell, tráfego, recorrência) — destrava depois de 10 vendas validadas.

---

## A tese

Profissional bom não precisa virar influencer pra vender. Precisa de um sistema.

A maioria troca atenção por exaustão: posta todo dia, grava Reels, faz reunião, contorna objeção — e mal vende. O Sistema de Vendas Invisível inverte isso: um punhado de posts certos atrai quem já quer comprar, um script automático conduz a venda no Direct, e o Pix cai sem você de plantão. Menos esforço, mais conversão.

O sistema não te substitui. Ele executa, rápido, o que você já sabe que precisa fazer.

---

## Como o sistema pensa

`_memoria/` é o cérebro do teu negócio — teu discurso, tua palavra-chave, teus produtos. O Claude lê isso antes de cada resposta. Quanto melhor a memória, melhor o sistema.

`identidade/` é o rosto — tuas cores, tua fonte, teu tom.

`saidas/` é o resultado — cada PVD, bio e FVD que o sistema gera fica aqui, teu.

---

## A régua

Se um passo não termina em **algo publicado no Instagram**, é teoria — e teoria aqui é opcional. O sistema existe pra você publicar e vender, não pra estudar.

**Travou?** Roda `/comecar` — ele sempre sabe o próximo passo.
